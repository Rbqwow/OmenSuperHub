测试使用模拟时钟、硬件写入器和 WMI 会话，不访问真实硬件。覆盖性能模式稳定窗口、风扇目标重试、启动及恢复、固件保活、风扇读回异常，以及 HP WMI 类缺失时的原生 WMI 数据包、实例解析、取消和错误处理。CI 使用同一命令执行测试。

固件保活独立于监控和用户设置，每 30 秒执行一次。正常风扇目标不定时重写；设置变更、显式重新应用、写入失败或有效转速读回低于目标时才下发。等待温度时保留上一有效目标，持续失温仍按原规则进入最大风量保护。

实机验收：冷启动后检查性能上限和自动、固定、最大风量，观察至少三分钟，并验证睡眠恢复及重新接通电源。HP WMI 类缺失时日志应出现原生传输切换信息，风扇读数应持续有效。正常命令和采样不逐条记日志；保留 BIOS/WMI 错误和保护状态记录。原生路径仍使用 Windows 权限和串行总线锁，不重建 WMI 仓库或安装驱动。
